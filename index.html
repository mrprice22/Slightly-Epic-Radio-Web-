Slightly Epic Radio

A small radio player you can drop into any website: pick a station, press play.

Embed it


  
Use height="84" for embeds 440px wide or more. Narrower embeds stack the volume slider on its own row, so use height="124".


  
Auto-height (optional)

  
The player reports its height to the parent page. Add this once if you want the iframe to size itself:

  
<script>
addEventListener('message', function (e) {
  if (!e.data || e.data.type !== 'slightly-epic-radio:height') return;
  document.querySelectorAll('iframe.slightly-epic-radio').forEach(function (f) {
    if (f.contentWindow === e.source) f.style.height = e.data.height + 'px';
  });
});
</script>


  
Options

  

    
ParameterExampleWhat it does

    
station?station=zen-gardenStarting station, by title (lowercase, dashes) or id. Otherwise the viewer's last station is used.

    
theme?theme=darklight, dark or auto (follows the visitor's system, default).

    
accent?accent=ff6a3dHex color for the play button, slider and equaliser.
